# E-Commerce SQL Worksheet

Advanced SQL practice using PostgreSQL through an E-Commerce Management System.

This repository contains practical SQL exercises focused on database relationships, analytical queries, optimization, and business reporting.

Built through hands-on learning and SQL problem solving.
